# XC:DE S2E site lists (hook sites compiled into the lifted modules)

`sites-sdk.txt` and `sites-rtld.txt` are copies of `xc2/sites/`: XC:DE S2E's `sdk`, `subsdk0-3` and `rtld` are
byte-identical to XC2 S2E 3.0.1's (docs/TARGET.md), so the same hooks apply. There is no `sites-main.txt`: no
XC:DE `main` hooks yet. Keep the copies in step with `xc2/sites/` when those change.
